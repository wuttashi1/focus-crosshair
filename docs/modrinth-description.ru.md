# Focus Crosshair

**Твоя форма. Твоё движение. Твой прицел.**

Настраиваемый прицел с пружинной анимацией для **Minecraft Java 26.2 / Fabric**. Раскрывается при наведении в воздух, сжимается над целью и возвращается с заметным отскоком. Только визуальные эффекты, только на клиенте.

## Собери свой прицел

**Пять встроенных форм:** Focus, Скобки, Ромб, Кольцо и Шеврон. **Пять цветовых палитр:** Иней, Слоновая кость, Мята, Янтарь и Сирень. Любую форму можно сочетать с любой палитрой или настроить цвета отдельно для воздуха, блоков, взаимодействий и существ.

Меняй масштаб, длину и толщину линий, центральный зазор, размер точки, прозрачность, обводку и угол поворота. Все формы используют общую систему анимации.

## Больше отскока и выраженный фокус

В **1.1** прицел по умолчанию стал более пружинистым. **Отскок**, **скорость анимации** и **сила импульсов** настраиваются независимо.

Задай отдельные множители размера и зазора для воздуха, блоков, интерактивных блоков и существ. Дополнительная реакция на расстояние сильнее сжимает прицел при приближении к уже выбранной цели и раскрывает его при удалении. Сила эффекта и диапазон расстояния регулируются.

Меняется только рисунок. Мод не влияет на наведение, камеру, ввод мыши, raycast, дальность взаимодействия или хитбоксы и не отправляет пакеты.

## Настройки с живым предпросмотром

Шесть разделов: **Стили, Форма, Анимация, Фокус, Эффекты и Цвета**.

Предпросмотр использует тот же рендерер, что и игровой прицел. Включи автоматическую смену целей, выбери конкретную цель, переключи близкое и дальнее расстояние или проиграй импульс атаки и попадания. Масштаб **1× или 3×** помогает рассмотреть детали. При редактировании цвета выбирается соответствующая цель.

Изменения применяются сразу, сохраняются при выходе. Дополнительные настройки доступны через колесо мыши или кнопки страниц. Интерфейс подстраивается под размер GUI; есть сброс к стандартным значениям.

## Загрузи свой PNG

Нажми **«Загрузить PNG…»** в разделе «Стили»: выбери файл через встроенный просмотр папок и дисков, вставь путь или перетащи PNG в окно настроек.

- Статичный PNG до **512 × 512 пикселей** и **1 МиБ**. Рекомендуется прозрачный фон.
- Копия сохраняется в `config/focuscrosshair/custom.png`. Исходный файл не меняется.
- Пропорции сохраняются; размер и окрашивание в цвета целей настраиваются.
- Свой PNG реагирует на масштаб, отскок, поворот и импульсы. Внутренний зазор и центральная точка остаются частью изображения.
- Текстура загружается один раз. Если сохранённый файл пропал или повреждён, используется Focus. Неудачный импорт не заменяет предыдущий рисунок.

## Реакции на действия

- Движение, спринт, приседание, прыжок, приземление, плавание и полёт на элитрах.
- Импульсы атаки, взаимодействия и получения урона; подтверждение попадания по событиям сервера.
- Тонкий индикатор из 16 сегментов с фактическим клиентским прогрессом разрушения блока.
- Использование еды, напитков, лука, арбалета, щита и других предметов.
- Отключаемая пульсация при низком здоровье и дыхание в покое. Дыхание по умолчанию выключено.

Эффекты отключаются отдельно. Индикатор перезарядки атаки сохраняется. Учитываются вид от первого лица, режим наблюдателя, F1 и отладочный прицел; в меню и во время сна игровой прицел скрыт.

## Установка и настройка

Нужны **Minecraft 26.2**, **Fabric Loader 0.19.5+**, **Fabric API 0.161.0+26.2** и **Java 25+**. Помести `focus-crosshair-1.1.0.jar` в `mods`. Серверу мод не нужен.

**Mod Menu необязателен.** Открой настройки через него или назначь **«Открыть настройки Focus Crosshair»** в настройках клавиш, категория Focus Crosshair. Есть отдельная клавиша включения и отключения. Обе изначально не назначены.

Конфигурация: `config/focuscrosshair.json`. Настройки из 1.0 сохраняются, новые параметры получают значения по умолчанию для 1.1. Вручную редактируй JSON при закрытой игре. Цвета: `#AARRGGBB`.

Интерфейс переведён на русский, английский и немецкий.

## Совместимость

Сборка под **26.2**. Для версии 1.1 проверены сборка и логика; запуск в Minecraft не проводился. Более поздние 26.x, Vulkan и сочетания с Sodium, Iris, Spatial GUI и другими HUD-модами отдельно не проверены.

Рисование через GUI API Minecraft, без прямых вызовов OpenGL. Другой мод прицела может получить приоритет. Нестандартные взаимодействия модифицированных блоков могут выглядеть как обычный блок; подтверждение попаданий зависит от событий сервера. Визуальный магнетизм сжимает сегменты, не сдвигая центр прицеливания.
