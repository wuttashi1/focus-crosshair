# Focus Crosshair

**Немного движения. Больше выразительности.**

Focus Crosshair заменяет стандартный прицел компактным анимированным прицелом, который реагирует на ваши действия и объекты под ним. Четыре аккуратных сегмента, отключаемая центральная точка, спокойные цвета и плавные движения.

![Focus Crosshair в игре](https://raw.githubusercontent.com/wuttashi1/focus-crosshair/main/docs/assets/gameplay.gif)

*Другие визуальные моды и ресурспаки на скриншоте в комплект не входят.*

## Возможности

- **Фокус на цели.** Прицел слегка сжимается при наведении на блоки и существ; поддерживаемые интерактивные блоки имеют отдельное ненавязчивое состояние.
- **Пружинная анимация.** Плавные изменения размера, зазора, прозрачности и визуальных эффектов.
- **Реакция на движение.** Небольшие эффекты при спринте, приседании, прыжках, приземлении, плавании и полёте на элитрах.
- **Обратная связь в бою.** Короткие импульсы атаки, получения урона и подтверждённого сервером попадания.
- **Прогресс разрушения.** Тонкий индикатор из 16 сегментов показывает фактический клиентский прогресс добычи блока.
- **Использование предметов.** Анимации еды, питья, зарядки лука и арбалета, щита и других действий.
- **Настройка под себя.** Цвета, прозрачность, размер, толщина линий, зазор и сила анимации. Отдельные эффекты и центральную точку можно отключить.

Пульсация при низком здоровье остаётся едва заметной. Дыхание прицела в покое по умолчанию отключено.

## Только визуальные эффекты

Мод не меняет наведение, камеру, ввод мыши, дальность взаимодействия, хитбоксы или выбор цели. Не отправляет пакеты и не требует установки на сервер.

Визуальный фокус работает через сжатие сегментов. Центральная точка остаётся в точке прицеливания. Стандартный индикатор перезарядки атаки сохраняется; прицел учитывает F1, режим наблюдателя, вид от первого лица и отладочный прицел, скрывается в меню.

## Установка

Нужны **Minecraft Java 26.2**, **Fabric Loader 0.19.5+**, **Fabric API для 26.2** и **Java 25+**.

Поместите JAR в папку `mods`. Для настройки в игре можно установить **Mod Menu** — это необязательная зависимость.

## Настройки

Используйте экран настроек в Mod Menu или файл `config/focuscrosshair.json` при закрытой игре. Изменения в интерфейсе применяются сразу и сохраняются при выходе.

Назначьте клавишу переключения в **Настройки → Управление → Назначение клавиш → Focus Crosshair**. По умолчанию клавиша не назначена. Отключение возвращает предыдущий прицел.

Включены русский, английский и немецкий переводы интерфейса.

## Совместимость

Мод собран и запущен на **26.2**. Более поздние 26.x ещё не проверены. Рисование использует GUI API Minecraft без прямых вызовов OpenGL. Vulkan, Sodium, Iris, Spatial GUI и другие HUD-моды требуют отдельной проверки; другой мод прицела может получить приоритет.

Некоторые взаимодействия модифицированных блоков могут отображаться обычным состоянием. Подтверждение попаданий зависит от событий урона, полученных от сервера.
